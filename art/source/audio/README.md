# Original game audio

Generated with `python tools/generate_game_audio.py` (NumPy, SciPy, SoundFile). All 23 effects are mono 44.1 kHz PCM16 WAV. Two original stereo Ogg Vorbis scores: refuge 64 seconds; expedition 51.2 seconds. Music uses circular placement and wrapped room reflections for continuous full-file looping. No sampled material, voices, third-party music, Higgsfield or other AI audio service was used.

The deterministic seed and per-file measurements/hashes are recorded in manifest.json. The score uses an original D-minor progression, suspended pads, glass/electric-piano motif, bass and restrained dockyard percussion. The preview in output/audio-refresh/preview.wav demonstrates the score with selected effects.
