# Titan-01 Mk II — PixelLab

Proposta visual gerada em 29/09/2026. A frente foi criada no PixelLab a partir do Titan v5 com edição de imagem; o modelo de personagem v3 expandiu essa proposta para oito direções. Os PNGs originais do serviço estão em `Idle/rotations/` (176 × 176 px, transparência). `titan_mk2_preview.png` reúne as oito vistas para avaliação; `titan_mk2_new.zip` é o pacote original.

- Imagem conceitual: `../titan_mk2/titan_mk2_concept.png` (job `90ae48b1-592f-4fff-9c7a-bfd74858bb41`).
- Personagem PixelLab: `47119649-7c8e-47a7-9708-db697abe441b`.
- Direção de arte: blindagem verde-oliva e latão mais angular, visor fechado com olhos ciano, núcleo frontal maior, canhão em um braço, mão mecânica no outro e conjunto de energia nas costas.

São poses paradas, sem ciclo de caminhada, tiro ou turbo. O jogo usa `assets/mech/titan_v5.png`, um atlas animado de cinco vistas e dez colunas; esta proposta ainda não o substitui.
